# The Gate V1 Sample

This folder contains a split sample version of V1 for GitHub sharing.

- `frontend/` contains the V1 web UI files.
- `backend/` contains the Express API and JSON storage.

Run locally:

```powershell
cd backend
npm install
node server.js
```

Then open:

- `http://127.0.0.1:5501/`
- `http://127.0.0.1:5501/dashboard.html`
